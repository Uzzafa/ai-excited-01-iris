"IRIS ENGINE" is a colossal eye of light frozen one instant before it opens: forty-eight emissive blades of a slit pupil, plasma arcs and one off-axis shockwave, hit from a rolled three-quarter camera with a cyan rim that gives the void an edge. It is made by a single dependency-free TypeScript file that ray-marches a signed-distance scene at 1024x1024, blooms and tonemaps the HDR buffer in software, and writes the PNG with a hand-built encoder (zlib deflate, a computed CRC32 table, IHDR/IDAT/IEND).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
